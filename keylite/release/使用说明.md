# KeyTree

## 安装与启动

运行同目录的 `KeyTree-Setup.exe`，按安装向导完成安装，通过桌面或开始菜单的 **KeyTree** 启动。程序不依赖 Node.js、Rust 或开发服务器。

安装包面向 Windows x64；本次已在 Windows 10 专业版 64 位（10.0.19045）完成安装和启动检查。本机安装位置为 `%LOCALAPPDATA%\Programs\KeyTree`；安装向导的默认位置可能不同，以实际选择为准。

程序依赖 Microsoft Edge WebView2 Runtime。已安装时直接使用；缺少时安装器会尝试从 Microsoft 下载补装，因此首次安装可能需要联网。本次没有卸载系统 WebView2，未验证缺失运行时的安装分支。

## 文件校验与系统提示

`SHA256SUMS.txt` 包含安装包的 SHA-256，可使用 PowerShell 校验：

```powershell
Get-FileHash .\KeyTree-Setup.exe -Algorithm SHA256
```

本包未做代码签名，Windows 可能显示“未知发布者”或 SmartScreen 提示。校验值用于核对文件完整性，不是代码签名或安全审计证明。

## 日常使用

打开已有 `.kdbx`，或新建密码库。请妥善保管主密码和密钥文件；遗失后无法绕过加密恢复数据。

设置 → 数据 → 多版本加密备份，可进行备份、解密验证预览和另存恢复副本。单份上限 64 MiB，最多保留 30 份、合计 256 MiB；恢复只另存新文件，不替换当前库。旧备份可能仍使用旧主密码或密钥文件。本地备份不等于异地容灾，重要密码库应另外保存受保护的副本。

WebDAV 同步由用户手动触发，不会自动同步；同一本地库不要同时交给云盘客户端与内置同步管理。
