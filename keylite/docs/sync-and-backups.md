# 同步快捷入口与多版本备份

## 主界面同步快捷条

主界面顶部显示本机同步配置和当前会话状态。未配置时点击“配置同步”直接进入设置的同步页；已配置时点击“立即同步”复用原有的安全同步流程，失败后可以点击“重试同步”。

- 只有用户点击才连接网盘，不是自动同步。快捷入口不授权首次创建；首次创建仍按服务能力和同步设置处理，坚果云只更新已有文件。
- 设置页、条目编辑抽屉、快速面板或其他操作进行中，快捷同步会让路。先完成编辑再同步，避免合并改变尚未提交的草稿。
- “上次上传确认”是历史时间，不代表远端现在没有新修改；重新打开库默认“尚未检查远端”。“本地已保存”和“已上传确认”是不同状态。
- 连接测试仍只读；它不会把状态改成已同步。原有强 ETag / 坚果云裸 ETag 原样 `If-Match`、412 冲突停止及锁定取消规则不变。

## 多版本加密备份

入口：**设置 → 数据 → 多版本加密备份**。

KeyTree 在覆盖已有有效 KDBX 前，先保留上一版原始密文。也可以点击“立即备份”，备份当前成功落盘的版本。原有 `.bak` 滚动备份和解锁页的恢复入口不变，多版本备份是额外保护。

- 位置：本地库完整路径后加 `.keytree-backups` 的目录。例如 `vault.kdbx.keytree-backups`。内置 WebDAV 只上传库文件，不上传这个目录。
- 保留上限：单库最多 **30 份、合计 256 MiB**，单份最多 **64 MiB**。新版本安全写入后，按时间清理超限的旧版本；创建时间不是条目最后修改时间。
- 自动清理只处理 KeyTree 规定命名的普通备份文件；其他文件或子目录不作为清理目标。不要手动重命名备份、修改目录结构或把其他资料放进该目录。
- 如果备份目录不可写、空间不足或当前文件超出支持上限，写入已有库可能中止；界面会保留未保存提示。请重试保存或另存到一个新的 KDBX 路径，不要强行锁定来掩盖失败。

## 验证与恢复预览

选择某个版本的“验证预览”。KeyTree 会先确认当前修改已保存，再用当前已解锁库的凭据真实解密该备份，并核对根组 UUID，确保属于同一个密码库。

预览只展示条目/分组数量，以及相对当前库新增、移除、内容或位置变化的条目数（包含回收站）。不展示密码或字段内容；不统计历史记录、附件、库设置等的具体差异。原始备份仍完整保留这些数据，摘要不是完整逐字段审计。

如果旧备份使用了旧主密码或旧密钥文件，当前凭据可能无法打开它。这不等于文件损坏；需通过独立途径保管并使用旧凭据，不能绕过解密验证。

## 另存恢复副本，不覆盖原库

验证成功后点击“另存恢复副本（不覆盖）”，选择一个**不存在的新文件名**。

- 取消文件对话框不会导出，也不会因为恢复操作而新建备份。
- 导出前会保留当前已保存版本。任何现有目标（包括原库、旧备份或同名恢复文件）都不会被覆盖；原生层也会检查，不只依赖界面确认。
- 成功后仍使用当前库，不自动打开恢复副本、不合并到当前库，也不自动上传。
- 导出需要目标文件系统支持安全的不覆盖写入。不支持时会拒绝导出，请改存本机 NTFS 目录；不会降级为覆盖写入。
- 锁定、切库、当前库有新改动或备份文件变化后，旧预览不可继续授权导出，需要重新验证。已经开始的加密文件复制无法撤回；取消保证的是不再开始后续操作。
- 如需使用恢复副本，请先单独核对，再从解锁页打开新文件。不要立即把旧版本覆盖到云端，让其他设备自动接收。

## 安全边界

KDBX 主体保持原有加密，但公开主密码提示仍是公开元数据。更换主密码或密钥文件不会重新加密已有历史副本；磁盘备份、云端历史和旧副本可能仍能用旧凭据打开。备份保留不等于永久擦除，也不是离线或异地容灾；重要库仍建议在独立设备另行保存受保护的副本。

开发验收使用临时目录、合成加密 KDBX 和隔离界面，不使用真实库、授权密码、剪贴板或真实网盘写入。真实跨设备服务验收范围以实际测试为准。
