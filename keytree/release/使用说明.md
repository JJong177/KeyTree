# 安装与使用

1. 运行 `KeyTree-Setup.exe`，选择中文或 English，按向导安装。
2. 启动 KeyTree，新建密码库或打开 `.kdbx`。
3. 添加账号后确认保存；同步与备份入口都在“设置”中。

支持 Windows x64。安装版不需要 Node.js 或 Rust；缺少 WebView2 时会尝试联网补装。安装语言只影响向导。

**主密码和密钥文件请妥善保管，遗失后无法绕过加密恢复。** 当前安装包未签名，请核对来源及 [SHA-256 校验值](SHA256SUMS.txt)。
